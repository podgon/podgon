# api
Контракт OpenAPI 3.0.3 — `openapi.yaml`, пишется вручную (contract-first, [ADR-005](../docs/architecture.md)). Версия 3.0.3 выбрана потому, что инструмент проверки в тестах сервера (swagger-request-validator) пока не поддерживает 3.1.

- Сервер публикует файл по `GET /openapi.yaml` (Gradle копирует его в ресурсы при сборке).
- Интеграционные тесты сервера сверяют каждый запрос и ответ с контрактом (`IntegrationTestSupport.kt`); намеренно некорректные запросы помечаются `invalidRequests { }`.
- Клиент на этапе 3 генерируется из этого файла. Общие модели, правила валидации и коды ошибок — в [shared-contract](../shared-contract).
- Изменения контракта вносятся вместе с изменениями сервера, клиента и миграций БД.

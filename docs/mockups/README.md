# Макеты редизайна

Исходники интерактивного холста https://claude.ai/artifact/NMPh1rJE4DP4sEkA7T2b7U (версия 28, 2026-11-02).
Решения по дизайну — `docs/design.md`; здесь только файлы макетов.

- `canvas.json` — расположение артбордов (ряды по `y`: 0 — основные экраны, 1000 — состояния ленты,
  2000 — вход и профиль, 3000 — группы; шаг по `x` — 470).
- `*.dc.html` — артборды: разметка с подстановками `{{...}}`, условия и циклы (`sc-if`, `sc-for`), логика —
  `class Component extends DCLogic` с `renderVals()`. Свойства — `data-props` (варианты — редактор `enum`).
- Короткие файлы (`MainSearch`, `GroupInvite`, `AuthCode` и т. п.) — варианты экрана: `dc-import` основного
  артборда с нужным значением свойства (`screen`, `sheet`, `step`).
- Переходы между экранами — обычные ссылки `<a href="X.dc.html">` (работают в режиме Play).

Как обновить опубликованный холст из Claude Code: инструмент Artifact, `url` холста, `root` — эта папка,
`file_path` — `canvas.json`, в `files` — изменённые артборды по путям `project/<имя>.dc.html`. Публикация
отклоняется, если живые файлы не прочитаны в сессии, — сначала прочитать их (`action: read`, `paths`).
Холст могли править в браузере: перед правкой сверить живую версию с этой папкой.

Это прототип: данные выдуманные, состояние экранов между собой не связано, кнопки нереализованного
функционала ничего не делают, у всех пользователей аватар по умолчанию.
